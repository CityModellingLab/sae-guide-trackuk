Area-level SAE model

A Bayesian spatio-temporal extension of the Fay–Herriot model

Theory in brief

The area-level model treats each direct estimate hat{\mu}^{w}_{jt} as a noisy observation of a true estimate \mu_{jt}:

\begin{aligned} \hat{\mu}^{w}_{jt} \mid \mu_{jt} &\sim \mathcal{N}(\mu_{jt}, \psi_{jt}), \\ \mu_{jt} &= \alpha + \mathbf{x}_{jt}^{T}\boldsymbol{\beta} + u_j + v_t. \end{aligned}

Here, \psi_{jt} is the direct-estimation sampling variance, \mathbf{x}_{jt} contains area-level predictors, u_j is an area effect, and v_t is a time effect.

The fitted model produces the area-time estimate by combining the direct estimate, its sampling variance, and the model prediction:

\hat{\mu}_{jt} = \widehat{\mathbb{E}}(\mu_{jt} \mid \hat{\mu}^{w}_{jt}, \psi_{jt}, \mathbf{x}_{jt}).

Estimation approach

Target estimand
  • Outcome and Population: Share of adults who cycle for transport frequently
  • Geography: MSOAs in Wales
  • Time: 2021, 2023, and 2025

Area-level SAE uses direct estimates as the modelling input. In the Fay–Herriot area-level model, each direct estimate for an MSOA-year cell is treated as a noisy observation of the underlying frequent-cycling rate, with its sampling variance determining how much weight the model gives to that estimate. The model borrows strength across MSOAs and survey years through spatial and temporal random effects, while area-level predictors, obtained from aggregated benchmarked sources such as ONS UK Census 2021, help explain systematic differences in the frequent cycling estimand across areas.

The missing or zero sampling variances of direct estimates need to be handled, because this controls how much weight each direct estimate receives in the area-level model.

  • For area-time cells without a direct estimate or variance, we assign the maximum observed positive sampling variance, signalling high uncertainty. Their estimates will be mostly determined by the model predictions.
  • Because the outcome is binary (1 for cycling frequently, 0 otherwise), very small samples can produce a variance of 0 when all sampled respondents give the same response. We also assign these cells the maximum observed positive sampling variance.
max_variance <- max(direct_bike$variance[direct_bike$variance > 0], na.rm = TRUE)

direct_bike <- direct_bike |>
  mutate(
    adj_variance = case_when(
      is.na(direct_estimate) ~ max_variance,
      is.na(variance) ~ max_variance,
      variance <= 1e-8 ~ max_variance,
      TRUE ~ variance
    )
  )

2 Fit and evaluate models

Each model uses the direct estimate as the response. The sampling variance from the direct estimation is passed to INLA as known observation-level uncertainty, so cells with noisy direct estimates receive less weight. We define these model specifications and fit each one to the direct estimates using INLA.

Model Name Specifications
M1 +TempSpatial Temporal and spatial effect
M2 +AvgAge M1 plus mean adult age
M3 +PopdensCaraccess M2 plus population density and share of adults with car access

The choice of spatial and temporal models should reflect assumptions about how residual variation is structured across space and time.

Temporal model Description
rw1 First-order random walk: smooths neighbouring time periods.
rw2 Second-order random walk: smooths changes in the trend over longer time series.
ar1 Autoregressive effect: assumes correlation decays with time distance, so closer years are more similar than distant years.
Spatial model Description
besag Smooths estimates across neighbouring areas, capturing spatially structured residual variation.
bym2 Updated BYM model with a mixing parameter, phi, which indicates how much residual variation is spatially structured.

With only three survey years, rw1 is suitable because it smooths neighbouring waves. Spatially, bym2 is appropriate because it allows the model to borrow strength from neighbouring MSOAs while still capturing unstructured local variability.

m1_formula <- direct_estimate ~
  f(
    area_inla_id,
    model = "bym2",
    graph = spatial_graph_file,
    scale.model = TRUE,
    constr = TRUE
  ) +
  f(time_inla_id, model = "rw1", constr = TRUE)

m2_formula <- update(m1_formula, . ~ . +
  scaled_age_adult_mean
)

m3_formula <- update(m2_formula, . ~ . +
  scaled_pop_density +
  scaled_caraccess_adult_share
)

model_formulas <- list(
  "M1 +TempSpatial" = m1_formula,
  "M2 +AvgAge" = m2_formula,
  "M3 +PopdensCaraccess" = m3_formula
)
fit_fh_model <- function(formula) {
  inla(
    formula = formula,
    family = "gaussian",
    data = model_data,
    scale = 1 / model_data$adj_variance,
    control.family = list(
      hyper = list(
        prec = list(initial = 0, fixed = TRUE)
      )
    ),
    control.predictor = list(compute = TRUE),
    control.compute = list(waic = TRUE, config = TRUE)
  )
}

fh_fits <- lapply(model_formulas, fit_fh_model)
Note

When fitting area-level SAE models with INLA, these arguments are needed:

  • control.predictor = list(compute = TRUE) returns fitted values for every row. In an area-level model, these are the final estimates for each area-time row.
  • scale passes the inverse sampling variance to INLA, so less precise direct estimates get smoothed more.
  • control.family fixes the Gaussian residual precision because the direct-estimate variances already provide the uncertainty.
  • control.compute = list(waic = TRUE, config = TRUE) requests WAIC for comparing model fit and stores the configuration needed for posterior sampling.

Model fit is compared with WAIC (Widely Applicable Information Criterion), a global predictive-fit measure returned by INLA. Lower values indicate better expected prediction after penalising model complexity.

3 Estimation with posterior draws

Posterior draws from the selected INLA fit give area-level SAE estimates for each MSOA-year cell. The fitted-value draws are summarised into the posterior mean, variance, and 95% credible interval.

Note

INLA stores the fitted values inside each posterior draw’s latent vector. The fitted-value rows are named Predictor....

# Draw 300 posterior samples from the selected fit.
set.seed(100)
posterior_draws <- inla.posterior.sample(
  n = 300,
  result = fh_selected_fit
)
# Keep the model prediction rows for each MSOA-year cell.
prediction_draws <- sapply(posterior_draws, \(draw) {
  prediction_rows <- startsWith(rownames(draw$latent), "Predictor")
  as.numeric(draw$latent[prediction_rows, 1])
})

The matrix prediction_draws has one MSOA-year estimate per row and one posterior draw per column. Posterior means, variances, and 95% credible intervals are computed directly from this draw matrix.

final_fh_results <- model_data |>
  select(area_id, time_id) |>
  bind_cols(
    tibble(
      fh_estimate = rowMeans(prediction_draws),
      fh_variance = apply(prediction_draws, 1, var),
      fh_lower = apply(prediction_draws, 1, quantile, probs = 0.025, names = FALSE),
      fh_upper = apply(prediction_draws, 1, quantile, probs = 0.975, names = FALSE)
    )
  ) |>
  mutate(
    fh_ci_width = fh_upper - fh_lower
  )

The area-level SAE estimates are less jagged across neighbouring areas and show clearer broad regional structure than the direct estimates. In sparsely sampled MSOA-year cells, the FH estimate depends heavily on area-level predictors and random effects because the direct estimate contributes limited local information. The model therefore cannot use within-area respondent variation beyond what is already captured in the direct estimate. Unit-level models address this by modelling individual outcomes with respondent-level predictors.

4.2 Adding Temporal and Spatial Effects

The selected area-level model estimates hyperparameters for the temporal and spatial random effects. These parameters show how much residual variation remains after accounting for the fixed-effect predictors and sampling variances, and how that remaining variation is structured across time and space.

  • tau is the precision of a random effect, or the inverse of its variance. Higher precision means less residual variation in that component. A higher temporal tau than spatial indicates a smoother time pattern with smaller differences between neighbouring survey years than between MSOAs. The temporal random effect keeps wave-to-wave differences explicit instead of pooling the three waves into one period.

  • phi is the BYM2 mixing parameter for the area random effect. It describes how much of that residual area effect is spatially structured. A lower phi here (less than 0.5) means the remaining area differences are mostly local and less strongly explained by adjacency. This can also be due to sparse direct estimates in many areas, which give the model less reliable area-level evidence for learning a coherent spatial pattern.

4.3 Adding Predictors

Besides comparing models using WAIC, we should also inspect how the estimates change locally. This helps identify where the model shifts the target estimates and whether those changes are substantively plausible. In this area-level model, adding predictors changes the model prediction for each area-time cell; when those predictors are informative, unstable direct estimates are pulled more strongly toward the updated predictions. Models should therefore be judged not only by their global predictive fit, as summarised by WAIC, but also by whether they produce locally defensible adjustments to the estimates.

Here we compare M1 with M3, which adds average age, population density, and car access.

Code 
predictor_change <- all_fh_results |>
  transmute(
    area_id,
    estimate_change = .data[["fh_estimate__M3 +PopdensCaraccess"]] - .data[["fh_estimate__M1 +TempSpatial"]]

model_data |>

  mutate(
