Small Area Estimation with Poststratification

A Bayesian spatio-temporal extension

Theory in brief

Let c index poststratification cells within area j and time t. The cells are defined by whichever population variables are available for poststratification. In a unit-level MRP approach, a binary cycling outcome can be modelled at the respondent level as

\begin{aligned} Y_{ijt} &\sim \mathrm{Bernoulli}(\pi_{ijt}) \\ \mathrm{logit}(\pi_{ijt}) &= \alpha + z_{ijt}^{T}\beta + u_j + v_t . \end{aligned}

where z_{ijt} is a vector of respondent-level predictors used to define or adjust the poststratification cells, \beta contains their coefficients, u_j is an area effect, and v_t is a time effect. The fitted model gives predicted cell means for the binary frequent-cycling indicator in each poststratification cell:

\hat{\pi}_{jtc} = \widehat{\mathbb{E}}(Y \mid j,t,c).

The poststratification step combines those cell predictions with population counts N_{jtc} available or estimated for the same cells. Area-time estimates are then population-weighted averages of the cell predictions. \hat{\mu}_{jt}^{\mathrm{MRP}} = \frac{\sum_c N_{jtc}\hat{\pi}_{jtc}} {\sum_c N_{jtc}}.

Estimation approach

Target estimand
  • Outcome and Population: Share of adults who cycle for transport frequently
  • Geography: MSOAs in Wales
  • Time: 2021, 2023, and 2025

MRP extends the unit-level SAE workflow by combining a respondent-level outcome model with a poststratification table describing the target population. For our estimand, we model the binary frequent-cycling indicator using age_band, sex, car_access, and spatial and temporal random effects. We then produce predicted cell means for the binary frequent-cycling indicator for each age_band × sex × car_access population cell and aggregate them to MSOA-year estimates using population weights. Uncertainty is propagated by repeating this aggregation across posterior draws.

In the poststratification step, our poststratification tables, sourced from ONS UK Census 2021, only observes the 2021 population counts for each age_band-sex-car_access cell for each MSOA,. For the 2023 and 2025 estimands, the model can still estimate different area-time outcomes through the temporal and spatial terms, but the poststratification weights are held fixed, assuming that local demographic and car-access composition does not change across the survey years. In other words, N_{jtc} = N_{jc,2021} for all three waves.

1 Prepare modelling and poststratification data

The MRP workflow needs two inputs:

  • poststrat_data, the population cells over which predictions are averaged.
  • model_data, the sampled respondent records used to fit the model;

1.1 Population poststratification data

First, we load the age-sex-car poststratification table and align its age_band, sex, and car_access categories with the survey model data.

The candidate models are fitted using only the respondent rows. This keeps model fitting separate from the poststratification step.

fit_mrp_model <- function(formula) {
  inla(
    formula = formula,
    family = "binomial",
    Ntrials = 1,
    data = model_data,
    control.predictor = list(compute = TRUE),
    control.compute = list(waic = TRUE, config = TRUE)
  )
}

mrp_fits <- lapply(model_formulas, fit_mrp_model)

3 Poststratification with posterior draws

At this point, having selected our final model, we use poststratification to convert its cell-level predictions into the target MSOA-year estimates. That means, each age_band x sex x car_access cell prediction is weighted by its population count, then aggregated within each MSOA-year. We first evaluate posterior draws for every poststratification cell; the cell point estimate is the posterior mean.

Code 
set.seed(100)
posterior_draws <- inla.posterior.sample(300, mrp_final_fit)

latent_names <- rownames(posterior_draws[[1]]$latent)
fixed_terms <- rownames(mrp_final_fit$summary.fixed)

fixed_effect_terms <- tibble(
  term = fixed_terms,
  latent_term = paste0(term, ":1")
)

area_effect_terms <- tibble(
  area_inla_id = area_index$area_inla_id,
  term = paste0("area_inla_id:", area_inla_id)
)

time_effect_terms <- tibble(
  time_inla_id = time_index$time_inla_id,
  term = paste0("time_inla_id:", time_inla_id)
)

stopifnot(all(fixed_effect_terms$latent_term %in% latent_names))
stopifnot(all(area_effect_terms$term %in% latent_names))
stopifnot(all(time_effect_terms$term %in% latent_names))

poststrat_fixed_matrix <- model.matrix(
  ~ age_band + sex + car_access,
  data = poststrat_data
)[, fixed_terms, drop = FALSE]

fixed_draws <- sapply(posterior_draws, \(draw) {
  values <- as.numeric(draw$latent[fixed_effect_terms$latent_term, 1])
  names(values) <- fixed_effect_terms$term
  values
})

area_draws <- sapply(posterior_draws, \(draw) {
  values <- as.numeric(draw$latent[area_effect_terms$term, 1])
  names(values) <- area_effect_terms$area_inla_id
  values
})

time_draws <- sapply(posterior_draws, \(draw) {
  values <- as.numeric(draw$latent[time_effect_terms$term, 1])
  names(values) <- time_effect_terms$time_inla_id
  values
})

poststrat_draws <- matrix(
  NA_real_,
  nrow = nrow(poststrat_data),
  ncol = length(posterior_draws)
)

for (draw_id in seq_along(posterior_draws)) {
  linear_predictor <- as.numeric(poststrat_fixed_matrix %*% fixed_draws[, draw_id]) +
    area_draws[as.character(poststrat_data$area_inla_id), draw_id] +
    time_draws[as.character(poststrat_data$time_inla_id), draw_id]

  poststrat_draws[, draw_id] <- plogis(linear_predictor)
}

cell_mean_predictions <- tibble(cell_mean = rowMeans(poststrat_draws))

cell_point_estimates <- bind_cols(poststrat_data, cell_mean_predictions)

area_year_point_estimates <- cell_point_estimates |>
  group_by(area_id, time_id) |>
  summarise(
    weighted_cell_sum = sum(cell_mean * pop_count),
    population_total = sum(pop_count),
    .groups = "drop"
  ) |>
  mutate(mrp_point_estimate = weighted_cell_sum / population_total) |>
  select(area_id, time_id, mrp_point_estimate)

The final output for SAE also needs uncertainty estimates. To propagate uncertainty through poststratification, we repeat the same population-weighted aggregation across posterior draws. Each draw is already on the response scale, so we can weight and aggregate the draw matrix directly.

  group = area_year_id, reorder = FALSE)

It is essential to caveat these estimates with the fact that we are reusing the same age-sex-car population composition of one year (2021) to estimate for the other two waves (2023, 2025) and letting the modelled time effect capture changes in the outcome. This is only possible if the relative age_band x sex x car_access poststratification weights stay consistent throughout the target periods, an assumption that must be made explicit.

5 Appendix: Enhance shallow poststratification with contextual predictors

Sometimes the population table is available for every target year but only at a shallow cell grain. For example, ONS mid-year population estimates can give MSOA-year counts by age and sex, but not by car access. In that setting we can still use MRP, but the model may only specify two unit-level predictors represented in the poststratification table.

That said, contextual predictors can then be added to help explain between-area (or, between-year) variation. Since these predictors vary by MSOA, not by respondent within an MSOA, this is weaker than having unit-level predictors and matching poststratification cells because they cannot represent how cycling behaviour differs between adults with and without car access inside the same age-sex cell.

Here is how the population poststratification data could look with only age_band and sex for three target years.

In the modelling step, the model specification uses age_band and sex as the poststratification-cell predictors, and adds the contextual area predictors directly as fixed effect terms.

shallow_base_formula <- indicator ~
  f(time_inla_id, model = "rw1", constr = TRUE) +
  f(
    area_inla_id,
    model = "bym2",
    graph = spatial_graph_file,
    scale.model = TRUE,
    constr = TRUE
  )

shallow_context_formula <- update(shallow_base_formula, . ~ . +
  age_band +
  sex +
  population_density +
  car_access_hhshare
)

shallow_context_fit <- inla(
  formula = shallow_context_formula,
  family = "binomial",
  Ntrials = 1,
  data = shallow_model_data,
  control.predictor = list(compute = TRUE),
  control.compute = list(waic = TRUE, config = TRUE)
)

It is worth noting that a quick WAIC comparison with our earlier best-fitting age-sex-car model suggests that contextual predictors add less to model performance than being able to include the additional unit-level car-access predictor. Therefore, wherever survey microdata and poststratification data are available and compatible, we should opt for richer model specifications.
