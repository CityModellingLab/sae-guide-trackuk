Small Area Estimation with Poststratification

A Bayesian spatio-temporal extension

Theory in brief

Let c index poststratification cells within area j and time t. The cells are defined by whichever population variables are available for poststratification. In a unit-level MRP approach, a binary walking outcome can be modelled at the respondent level as

\begin{aligned} Y_{ijt} &\sim \mathrm{Bernoulli}(\pi_{ijt}) \\ \mathrm{logit}(\pi_{ijt}) &= \alpha + z_{ijt}^{T}\beta + u_j + v_t . \end{aligned}

where z_{ijt} is a vector of respondent-level predictors used to define or adjust the poststratification cells, \beta contains their coefficients, u_j is an area effect, and v_t is a time effect. The fitted model gives predicted cell means for the binary frequent-walking indicator in each poststratification cell:

\hat{\pi}_{jtc} = \widehat{\mathbb{E}}(Y \mid j,t,c).

The poststratification step combines those cell predictions with population counts N_{jtc} available or estimated for the same cells. Area-time estimates are then population-weighted averages of the cell predictions. \hat{\mu}_{jt}^{\mathrm{MRP}} = \frac{\sum_c N_{jtc}\hat{\pi}_{jtc}} {\sum_c N_{jtc}}.

Estimation approach

Target estimand
  • Outcome and Population: Share of Adults who walk for transport daily
  • Geography: MSOAs in Wales
  • Time: 2021, 2023, and 2025

MRP extends the unit-level SAE workflow by combining a respondent-level outcome model with a poststratification table describing the target population. For our estimand, we model the binary frequent-walking indicator using age_band, sex, car_access, and spatial and temporal random effects. We then produce predicted cell means for the binary frequent-walking indicator for each age_band × sex × car_access population cell and aggregate them to MSOA-year estimates using population weights. Uncertainty is propagated by repeating this aggregation across posterior draws.

In the poststratification step, our poststratification tables with population counts for each age_band-sex-car_access cell for each MSOA were sourced from ONS UK Census 2021 so it only observes the composition for 2021. For the 2023 and 2025 estimands, the model can still estimate different area-time outcomes through the temporal and spatial terms, but the poststratification weights are held fixed, assuming that local demographic and car-access composition does not change across the survey years. In other words, N_{jtc} = N_{jc,2021} for all three waves.

1 Prepare modelling and poststratification data

The MRP workflow needs two inputs:

  • poststrat_data, the population cells over which predictions are averaged.
  • model_data, the sampled respondent records used to fit the model;

2 Fit and evaluate models

The observed respondent rows and the poststratification rows are combined before fitting. Rows with indicator = NA are not used in the likelihood, but INLA still returns their fitted values, which are needed for poststratification.

model_poststrat_data <- bind_rows(
  model_data |>
    mutate(row_type = "model"),
  poststrat_data |>
    mutate(row_type = "poststrat", indicator = NA_real_
    )
) |>
  select(
    row_type, 
    indicator, 
    age_band, 
    sex,
    car_access,
    time_inla_id, 
    area_inla_id
    )

fit_mrp_model <- function(formula) {
  inla(
    formula = formula,
    family = "binomial",
    Ntrials = 1,
    data = model_poststrat_data,
    control.predictor = list(compute = TRUE, link = 1),
    control.compute = list(waic = TRUE, config = TRUE)
  )
}

mrp_fits <- lapply(model_formulas, fit_mrp_model)

3 Poststratification

At this point, having selected our final model, we use poststratification to convert its cell-level predictions into the target MSOA-year estimates. That means, each age_band x sex x car_access cell prediction is weighted by its population count, then aggregated within each MSOA-year. We can apply this calculation using the posterior mean cell values returned above, which gives a simple point estimate for each cell:

Code 
poststrat_cell_rows <- which(model_poststrat_data$row_type == "poststrat")

cell_mean_predictions <- mrp_final_fit$summary.fitted.values |>
  as_tibble() |>
  slice(poststrat_cell_rows) |>
  transmute(cell_mean = mean)

cell_point_estimates <- bind_cols(poststrat_data, cell_mean_predictions)

area_year_point_estimates <- cell_point_estimates |>
  group_by(area_id, time_id) |>
  summarise(
    weighted_cell_sum = sum(cell_mean * pop_count),
    population_total = sum(pop_count),
    .groups = "drop"
  ) |>
  mutate(mrp_point_estimate = weighted_cell_sum / population_total) |>
  select(area_id, time_id, mrp_point_estimate)

However, the final output for SAE also needs uncertainty estimates. To propagate uncertainty through poststratification, we repeat the same population-weighted aggregation across posterior draws. The posterior draws used for this calculation are shown below.

The function inla.posterior.sample() gives plausible versions of the fitted model. For each draw, we keep the poststratification rows, convert fitted values from the logit scale to the original 0-1 scale, population-weight them within each MSOA-year, and summarise the resulting posterior distribution.

# Draw 300 posterior draws of the model fit
set.seed(100)
posterior_draws <- inla.posterior.sample(300, mrp_final_fit)

#  For each draw, keep the poststrat rows, convert values to the original scale 
predictor_rows <- startsWith(rownames(posterior_draws[[1]]$latent), "Predictor")
area_year_id <- paste(poststrat_data$area_id, poststrat_data$time_id, sep = "__")
poststrat_draws <- sapply(posterior_draws, \(draw) {
  plogis(as.numeric(draw$latent[predictor_rows, 1])[poststrat_cell_rows])
})

# Population-weight them
area_year_weighted_sums <- rowsum(poststrat_draws * poststrat_data$pop_count,
  group = area_year_id, reorder = FALSE)
area_year_populations <- rowsum(poststrat_data$pop_count,
  group = area_year_id, reorder = FALSE)
area_year_means <- area_year_weighted_sums / as.numeric(area_year_populations)

4 Final estimates and uncertainty

As with previous methods, we report the MRP estimates alongside the direct estimates and variance outputs in order to provide a full view of the direct survey evidence that accompanies the modelled estimates.

Code

  show_col_types = FALSE

  select(area_id, time_id, n, direct_estimate, variance)

The final estimates show frequent walking for transport increasing among Welsh adults from 2021, with some higher-estimate clusters around urban areas. This pattern was difficult to see in the direct estimates because they were too unstable when aggregated to the desired MSOA level.

It is essential to caveat these estimates with the fact that we are reusing the same age-sex-car population composition of one year (2021) to estimate for the other two waves (2023, 2025) and letting the modelled time effect capture changes in the outcome. This is only possible if the relative age_band x sex x car_access poststratification weights stay consistent throughout the target periods, an assumption that must be made explicit.

Compared to estimates obtained from other modelling approaches, the MRP estimates are understandably very close to the BHF estimates. Agreement with the direct estimates is much weaker as expected, reflecting the instability of sparse MSOA-year survey cells. The Fay–Herriot estimates tend to sit lower than MRP for many cells, suggesting stronger shrinkage toward lower area-year rates.

5 Appendix: Enhance shallow poststratification with contextual predictors

Sometimes the population table is available for every target year but only at a shallow cell grain. For example, ONS mid-year population estimates can give MSOA-year counts by age and sex, but not by car access. In that setting we can still use MRP, but the model may only specify two unit-level predictors represented in the poststratification table.

That said, contextual predictors can then be added to help explain between-area (or, between-year) variation. Since these predictors vary by MSOA, not by respondent within an MSOA, this is weaker than having unit-level predictors and matching poststratification cells because they cannot represent how walking behaviour differs between adults with and without car access inside the same age-sex cell.

Here is how the population poststratification data could look with only age_band and sex for three target years.

In the modelling step, the model specification uses age_band and sex as the poststratification-cell predictors, and adds the contextual area predictors directly as fixed effect terms.

shallow_context_formula <- indicator ~
  age_band +
  sex +
  population_density +
  car_access_hhshare +
  share_students +
  share_work_from_home +
  f(time_inla_id, model = "rw1", constr = TRUE) +
  f(
    area_inla_id,
    model = "bym2",
    graph = spatial_graph_file,
    scale.model = TRUE,
    constr = TRUE
  )

shallow_model_poststrat_data <- bind_rows(
  shallow_model_data |>
    mutate(row_type = "model"),
  shallow_poststrat_data |>
    mutate(row_type = "poststrat", indicator = NA_real_)
) |>
  select(
    row_type,
    indicator,
    age_band,
    sex,
    car_access_hhshare,
    population_density,
    share_work_from_home,
    share_students,
    time_inla_id,
    area_inla_id
  )

shallow_context_fit <- inla(
  formula = shallow_context_formula,
  family = "binomial",
  Ntrials = 1,
  data = shallow_model_poststrat_data,
  control.predictor = list(compute = TRUE, link = 1),
  control.compute = list(waic = TRUE, config = TRUE)
)

It is worth noting that a quick WAIC comparison with our earlier best-fitting age-sex-car model suggests that contextual predictors add less to model performance than being able to include the additional unit-level car-access predictor. Therefore, wherever survey microdata and poststratification data are available and compatible, we should opt for richer model specifications.

Finally, during the poststratification step, the fitted cell predictions are weighted only by the age-sex population counts for each MSOA-year to produce the estimates for each cell.

Code 
shallow_poststrat_cell_rows <- which(shallow_model_poststrat_data$row_type == "poststrat")

set.seed(101)

  shallow_poststrat_data$area_id,
  shallow_poststrat_data$time_id,
  sep = "__"
)

shallow_poststrat_draws <- sapply(shallow_posterior_draws, \(draw) {
  plogis(as.numeric(draw$latent[shallow_predictor_rows, 1])[shallow_poststrat_cell_rows])
})

shallow_area_year_weighted_sums <- rowsum(
  shallow_poststrat_draws * shallow_poststrat_data$pop_count,
  group = shallow_area_year_id,
  reorder = FALSE
)
shallow_area_year_populations <- rowsum(
  shallow_poststrat_data$pop_count,
  group = shallow_area_year_id,
  reorder = FALSE
)
shallow_area_year_means <- shallow_area_year_weighted_sums / as.numeric(shallow_area_year_populations)

shallow_area_year_summary <- tibble(
  area_year_id = rownames(shallow_area_year_means),
  shallow_mrp_estimate = rowMeans(shallow_area_year_means),
  shallow_mrp_variance = apply(shallow_area_year_means, 1, var),
  shallow_mrp_lower = apply(shallow_area_year_means, 1, quantile, probs = 0.025, names = FALSE),

shallow_mrp_results <- domain_frame |>
