Unit-level SAE model with poststratification

A Bayesian spatio-temporal extension of Multilevel Regression with Poststratification (MRP)

Theory in brief

Let c index poststratification cells within area j and time t. The cells are defined by whichever population variables are available for poststratification. In a unit-level SAE with poststratification approach, a binary cycling outcome can be modelled at the respondent level as

\begin{aligned} Y_{ijt} &\sim \mathrm{Bernoulli}(\pi_{ijt}) \\ \mathrm{logit}(\pi_{ijt}) &= \alpha + z_{ijt}^{T}\beta + u_j + v_t . \end{aligned}

where z_{ijt} is a vector of respondent-level predictors used to define or adjust the poststratification cells, \beta contains their coefficients, u_j is an area effect, and v_t is a time effect. The fitted model gives predicted cell means for the binary frequent-cycling indicator in each poststratification cell:

\hat{\pi}_{jtc} = \widehat{\mathbb{E}}(Y \mid j,t,c).

The poststratification step combines those cell predictions with population counts N_{jtc} available or estimated for the same cells. Area-time estimates are then population-weighted averages of the cell predictions. \hat{\mu}_{jt}^{\mathrm{post}} = \frac{\sum_c N_{jtc}\hat{\pi}_{jtc}} {\sum_c N_{jtc}}.

Estimation approach

Target estimand
  • Outcome and Population: Share of adults who cycle for transport frequently
  • Geography: MSOAs in Wales
  • Time: 2021, 2023, and 2025

Unit-level SAE with poststratification combines an outcome model fitted to survey microdata with a poststratification table describing the target population. This is the core structure of Multilevel Regression with Poststratification (MRP): model predictions are averaged over population cells. For this estimand, we model the binary frequent-cycling indicator using age_band, sex, car_access, and spatial and temporal random effects. We then produce predicted cell means for each age_band x sex x car_access population cell and aggregate them to MSOA-year estimates using population weights. Uncertainty is propagated by repeating this aggregation across posterior draws.

Here, the poststratification table is sourced from ONS UK Census 2021, giving the 2021 population count for each age_band x sex x car_access cell in each MSOA. For the 2023 and 2025 estimands, the model can still estimate different area-time outcomes through the temporal and spatial terms, but the poststratification weights are held fixed. This assumes that local demographic and car-access composition does not change across the survey years. In other words, N_{jtc} = N_{jc,2021} for all three waves.

1 Prepare modelling and poststratification data

There are two inputs when performing unit-level SAE with poststratification:

  • poststrat_data, the population cells over which predictions are averaged.
  • model_data, the survey microdata used to fit the model.

It is essential for the unit-level predictors to be identical to the ones present in the poststratification table. Therefore, age is grouped into the same broad Census age bands and sex is also recoded as Male and Female.

2 Fit and evaluate models

We fit binomial unit-level models to the survey microdata, then use them to predict area-time means. We specify three unit-level models to evaluate at the next step:

fit_mrp_model <- function(formula) {
  inla(
    formula = formula,
    family = "binomial",
    Ntrials = 1,
    data = model_data,
    control.predictor = list(compute = TRUE),
    control.compute = list(waic = TRUE, config = TRUE)

}

mrp_fits <- lapply(model_formulas, fit_mrp_model)

3 Poststratification with posterior draws

As with the previous model-based methods, the final MSOA-year estimates are obtained by aggregating predictions across posterior draws. The key difference is that the unit-level model is fitted to survey microdata, so its predictions can still reflect the composition of the survey sample instead of the real-world population if left unadjusted as done in the previous method. Poststratification addresses this by evaluating the fitted model over known population groups and reweighting those predictions by population counts, so the final estimates are aligned with the target population structure.

Posterior draws from the selected INLA fit produce MSOA-year estimates. Each draw provides fixed effects, spatial area effects, and temporal effects. The fitted model is evaluated over every age_band x sex x car_access population cell, transformed to the response scale, weighted by pop_count, and summarised as MSOA-year draws.

Note

Each posterior draw stores the fixed effects, spatial area effect, and temporal effect together in INLA’s latent vector. Fixed effects are labelled as term:1, while random effects are labelled as effect:index.

set.seed(100)
posterior_draws <- inla.posterior.sample(
  n = 300,
  result = mrp_final_fit
)

# Fixed-effect draw matrix
fixed_terms <- rownames(mrp_final_fit$summary.fixed)
fixed_draws <- sapply(posterior_draws, \(draw) {
  setNames(
    as.numeric(draw$latent[paste0(fixed_terms, ":1"), 1]),
    fixed_terms
  )
})

# Area-effect draw matrix
area_draws <- sapply(posterior_draws, \(draw) {
  setNames(
    as.numeric(draw$latent[paste0("area_inla_id:", area_ids), 1]),
    area_ids
  )
})

# Time-effect draw matrix
time_draws <- sapply(posterior_draws, \(draw) {
  setNames(
    as.numeric(draw$latent[paste0("time_inla_id:", time_ids), 1]),
    time_ids
  )
})

Each posterior draw is evaluated over every poststratification cell. The cell predictions are then weighted by population count and aggregated within each MSOA-year.

# Rebuild fitted model for each cell
prediction_matrix <- model.matrix(
  ~ age_band + sex + car_access,
  data = poststrat_data
)[, fixed_terms, drop = FALSE]

cell_draws <- sapply(seq_along(posterior_draws), \(draw_id) {
  cell_log_odds <- as.numeric(prediction_matrix %*% fixed_draws[, draw_id]) +
    area_draws[as.character(poststrat_data$area_inla_id), draw_id] +
    time_draws[as.character(poststrat_data$time_inla_id), draw_id]

  plogis(cell_log_odds) # For binomial model
})

# Aggregate and apply poststrat weight for each area-time
area_year_id <- paste(poststrat_data$area_id, poststrat_data$time_id, sep = "__")

aggregate_draws <- function(draw_matrix, weights, group) {
  weighted_sums <- rowsum(draw_matrix * weights, group = group, reorder = FALSE)
  population_totals <- rowsum(weights, group = group, reorder = FALSE)
  weighted_sums / as.numeric(population_totals)
}

prediction_draws <- aggregate_draws(
  draw_matrix = cell_draws,
  weights = poststrat_data$pop_count,
  group = area_year_id
)

The matrix prediction_draws has one MSOA-year estimate per row and one posterior draw per column. Posterior means, variances, and 95% credible intervals are computed directly from this draw matrix.

final_mrp_results <- tibble(area_year_id = rownames(prediction_draws)) |>
  separate(area_year_id, into = c("area_id", "time_id"), sep = "__", convert = TRUE) |>
  bind_cols(
    tibble(
      mrp_estimate = rowMeans(prediction_draws),
      mrp_variance = apply(prediction_draws, 1, var),
      mrp_lower = apply(prediction_draws, 1, quantile, probs = 0.025, names = FALSE),
      mrp_upper = apply(prediction_draws, 1, quantile, probs = 0.975, names = FALSE)
    )
  ) |>
  mutate(
    mrp_ci_width = mrp_upper - mrp_lower
  )

4 Appendix: Enhance shallow poststratification with contextual predictors

Sometimes the population table is available for every target year but only at a shallow cell grain. ONS mid-year population estimates can give MSOA-year counts by age_band and sex, but not by car_access. In that setting, poststratification can still be used, but only for unit-level predictors represented in the population table.

Contextual predictors can explain between-area or between-year variation, but they do not describe respondent composition within an MSOA. They cannot represent how cycling behaviour differs between adults with and without car access inside the same age-sex cell.
