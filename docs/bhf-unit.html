Spatio-Temporal Battese-Harter-Fuller Unit-Level Model

Predict small area estimates from survey microdata using temporal and spatial smoothing

BHF unit-level SAE models respondent records directly. The Bayesian extension used here combines respondent-level predictors with area and time random effects, then aggregates the fitted relationship to the area-time cells we want to estimate. In this example, each area-time cell is one MSOA-year cell.

Theory in brief

The unit-level route models respondent outcomes directly. For the area-time target \(\mu_{jt}\), a simple nested-error form is:

\[ y_{ijt} = \alpha + \mathbf{x}_{ijt}^{T}\boldsymbol{\beta} + u_j + v_t + \epsilon_{ijt}, \]

where \(\mathbf{x}_{ijt}\) are unit-level predictors, \(u_j\) is an area effect, and \(v_t\) is a time effect. The classical Battese–Harter–Fuller estimator can be applied to each area-time target:

\[ \hat{\mu}_{jt}^{\mathrm{EBLUP}} = f_{jt} \bar{y}_{jtS} + \left(\bar{\mathbf{X}}_{jt} - f_{jt} \bar{\mathbf{x}}_{jtS}\right)^T \hat{\boldsymbol{\beta}} + (1 - f_{jt})(\hat{u}_j + \hat{v}_t), \]

where \(f_{jt}=n_{jt}/N_{jt}\), \(\bar{y}_{jtS}\) and \(\bar{\mathbf{x}}_{jtS}\) are sample means in area \(j\) and time period \(t\), \(\bar{\mathbf{X}}_{jt}\) is the corresponding population mean of the predictors, and \(\hat{u}_j\) and \(\hat{v}_t\) are fitted area and time effects. The area effect can also be replaced by a structured spatial effect.

Target estimand
  • Target outcome and Population: Share of Adults who walk for transport daily
  • Geography: MSOAs in Wales
  • Time: 2021, 2023, and 2025

1 Prepare model and aggregation data

Before preparing the model inputs, we create a consistent numeric index for each area and survey year in the complete area-time domain. These indices are used by INLA to attach random effects to the correct area and period.

Code 
area_levels <- sort(unique(domain_frame[["area_id"]]))
time_levels <- sort(unique(domain_frame[["time_id"]]))

area_index <- tibble(
  area_id = area_levels,
  area_inla_id = seq_along(area_levels)
)

time_index <- tibble(
  time_id = time_levels,
  time_inla_id = seq_along(time_levels)
)

To include a spatial random effect, we also need an adjacency graph .adj as input. We again use Queen contiguity.

Code 
msoa_boundaries_sorted <- msoa_boundaries |>
  inner_join(area_index, by = "area_id") |>
  arrange(.data$area_inla_id)

msoa_neighbours <- poly2nb(
  msoa_boundaries_sorted,
  queen = TRUE,
  row.names = msoa_boundaries_sorted$area_id
)

spatial_graph_file <- tempfile(fileext = ".adj")

nb2INLA(
  file = spatial_graph_file,
  nb = msoa_neighbours
)

Now, we assemble the data needed to fit the unit-level model. Unit-level SAE modelling has two separate data-preparation steps:

  • prepare the respondent-level rows used to fit the model;
  • prepare the area-level rows used to aggregate the fitted relationship to area-time estimates.

1.1 Respondent model data

The respondent model data has one row per sampled person. For this constrained example we use:

  • indicator as the binary response, our target;
  • no_car as the unit-level auxiliary variable, our predictor;
  • time_id as the survey wave year identifier;
  • area_id as the area identifier;
Code 
unit_predictors <- read_csv(

2 Fit and evaluate models

We fit linear mixed models to respondent-level records, then use them to predict area-time means. This follows the BHF nested-error idea, extended here with temporal and spatial random effects.

Note

The response is binary, so this is a linear probability version of the BHF-style model.

The two models are:

Model Name Specifications
M1 Temporal + spatial Respondent outcome with a temporal random walk and BYM2 spatial MSOA effect
M2 +No-car M1 plus respondent-level no-car access, aggregated using the MSOA Census share of households with no car or van 
m1_formula <- indicator ~
  1 +
  f(time_inla_id, model = "rw1", constr = TRUE) +
  f(
    area_spatial_id,
    model = "bym2",
    graph = spatial_graph_file,
    scale.model = TRUE,
    constr = TRUE
  )

m2_formula <- indicator ~
  no_car +
  f(time_inla_id, model = "rw1", constr = TRUE) +
  f(
    area_spatial_id,
    model = "bym2",
    graph = spatial_graph_file,
    scale.model = TRUE,
    constr = TRUE
  )

model_formulas <- list(
  "M1 Temporal + Spatial" = m1_formula,
  "M2 +No-car" = m2_formula
)

INLA does not use a separate predict(newdata = ...) step; instead, it returns fitted values for every row in the input data. We therefore add aggregation rows for the area-time cells with indicator = NA for INLA to return fitted values for them.

Note

In this workflow, this feature allows area-time cells without survey data to also receive an estimate.

inla_input <- bind_rows(
  model_data |>
    transmute(
      row_type = "model",
      indicator,
      no_car,
      time_inla_id,
      area_spatial_id
    ),
  aggregation_data |>
    transmute(
      row_type = "aggregation",
      indicator = NA_real_,
      no_car,
      time_inla_id,
      area_spatial_id
    )
)

fit_bhf_model <- function(formula) {
  inla(
    formula = formula,
    family = "gaussian",
    data = inla_input,
    control.predictor = list(compute = TRUE),
    control.compute = list(waic = TRUE, dic = TRUE)
  )
}

bhf_fits <- lapply(model_formulas, fit_bhf_model)

WAIC compares the BHF fits to the sampled respondent outcomes. Here, the lower WAIC for M2 shows that adding the no-car predictor improves the temporal-spatial model enough to justify the extra term.

The temporal tau is high, suggesting that the survey-wave adjustments are relatively small. By contrast, the spatial tau is lower, indicating more remaining variation between MSOAs than between survey waves.

The BYM2 phi is above 0.5, so in this simple BHF model specification much of the remaining between-MSOA variation is spatially structured. By contrast, the lower phi in the Fay–Herriot model may reflect its richer specification: with more area-level predictors included, less residual between-MSOA variation is left for the spatial random effect to explain.

3 Report estimates and uncertainty

Using M2 as the selected model, we extract fitted values for all MSOA-year rows. The posterior mean is the final BHF estimate, and the posterior 95% interval represents its uncertainty.

Code 
aggregation_row_ids <- which(inla_input$row_type == "aggregation")

bhf_estimates <- as_tibble(
  bhf_fits[["M2 +No-car"]]$summary.fitted.values[
    aggregation_row_ids,
    ,
    drop = FALSE
  ]
) |>
  transmute(
    bhf_estimate = pmin(pmax(.data$mean, 0), 1),
    bhf_variance = .data$sd^2,
    bhf_lower = pmin(pmax(.data[["0.025quant"]], 0), 1),
    bhf_upper = pmin(pmax(.data[["0.975quant"]], 0), 1)
  ) |>
  mutate(
    bhf_ci_width = .data$bhf_upper - .data$bhf_lower
  ) |>
  bind_cols(
    aggregation_data |>
      select(
        area_id,
        msoa_name,
        time_id,
        no_car
      )
  ) |>
  relocate(area_id, msoa_name, time_id, no_car)

The scatterplot shows that BHF estimates are much smoother than the direct estimates and closer to the Fay–Herriot estimates, as expected for a model-based approach that borrows strength across area-time cells.

The BHF and Fay–Herriot estimates differ because the two models use the survey information differently. This simple BHF example is fitted to unweighted respondent records and uses only one respondent-level predictor. The final Fay–Herriot model starts from weighted direct estimates, uses their sampling variances, and includes a richer set of area-level predictors and spatio-temporal effects.

Adding more unit-level predictors such as age, sex, ethnicity, or employment status can help; aggregation then requires a population table with the joint distribution of those predictors for every area-time cell. This requirement leads to multilevel regression with poststratification: MRP fits a richer unit-level model and averages predicted outcomes over a poststratification table representing the target population.
