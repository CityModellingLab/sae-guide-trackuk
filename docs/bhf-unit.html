Unit-level SAE model with area summaries

A Bayesian spatio-temporal extension of the Battese–Harter–Fuller unit-level model

Theory in brief

The unit-level route models respondent outcomes directly. For the area-time target \mu_{jt}, a simple mixed-model form is:

Y_{ijt} = \alpha + x_{ijt}^{T}\beta + u_j + v_t + \epsilon_{ijt},

where x_{ijt} contains unit-level predictors, u_j is an area effect, and v_t is a time effect. The area effect can be replaced by a structured spatial effect, and a temporal effect v_t can be added to represent wave-to-wave dependence. To estimate the target for an area-time cell, the fitted model is evaluated using the corresponding population-level auxiliary summaries \bar{x}_{jt}:

\hat{\mu}_{jt}^{\mathrm{unit}} = \widehat{\mathbb{E}}(Y \mid j,t,\bar{x}_{jt}).

Estimation approach

Target estimand
  • Outcome and Population: Share of adults who cycle for transport frequently
  • Geography: MSOAs in Wales
  • Time: 2021, 2023, and 2025

Unit-level SAE with area summaries models survey microdata directly instead of starting from pre-aggregated direct estimates, which helps when direct estimates are too sparse or unstable to provide reliable modelling inputs. Here, the binary frequent-cycling indicator is modelled from the survey microdata using temporal and spatial random effects, with unit-level age, sex, and car_access added across model specifications.

This method follows the classic Battese–Harter–Fuller (BHF) unit-level SAE model but uses a generalised mixed model to handle both binary and continuous outcomes. The individual outcome is modelled using predictors present in the survey microdata, then evaluated using MSOA-level summaries of those predictors. Here, those summaries are extracted from ONS UK Census 2021 to produce the final MSOA-year estimates. This reduces reliance on unstable or missing direct estimates, but it assumes the area summaries of age, sex, and car_access adequately represent the target population composition in each MSOA-year cell.

1 Prepare model and aggregation data

There are two inputs when performing unit-level SAE:

  • model_data contains the survey microdata used to fit the model.
  • aggregation_data contains one row for each area-time cell we want to estimate.

2 Fit and evaluate models

We fit binomial unit-level models to the survey microdata, then use them to predict area-time means. We specify three unit-level models to evaluate at the next step:

Model Name Specifications
M1 +TempSpatial Temporal RW1 plus BYM2 spatial MSOA effect
M2 +Demographic M1 plus respondent age and sex
M3 +CarAccess M2 plus respondent-level car access 
m1_formula <- indicator ~
  1 +
  f(time_inla_id, model = "rw1", constr = TRUE) +
  f(
    area_inla_id,
    model = "bym2",
    graph = spatial_graph_file,
    scale.model = TRUE,
    constr = TRUE
  )

m2_formula <- update(m1_formula, . ~ . +
  age +
  female
)

m3_formula <- update(m2_formula, . ~ . +
  car_access
)

model_formulas <- list(
  "M1 +TempSpatial" = m1_formula,
  "M2 +Demographic" = m2_formula,
  "M3 +CarAccess" = m3_formula
)
fit_bhf_model <- function(formula) {
  inla(
    formula = formula,
    family = "binomial",
    Ntrials = 1,
    data = model_data,
    control.predictor = list(compute = TRUE),
    control.compute = list(waic = TRUE, config = TRUE)
  )
}

bhf_fits <- lapply(model_formulas, fit_bhf_model)
Note

When fitting unit-level SAE models with INLA, these arguments are needed:

  • control.predictor = list(compute = TRUE) returns fitted values for the respondent rows used in the likelihood.
  • control.compute = list(waic = TRUE, config = TRUE) requests WAIC for comparing model fit and stores the configuration needed for posterior sampling.

To compare the fitted models’ overall performance, we again use WAIC as a first check. Here, the car-access extension has the strongest WAIC support among the model specifications.

The random-effect table reports the posterior summaries for the temporal and spatial components in the selected unit-level specification. Higher precision means less residual variation in that component, while the BYM2 phi indicates how much of the area effect is spatially structured.

3 Estimation and aggregation with posterior draws

The aggregation step uses posterior draws from the selected INLA fit to produce unit-level SAE estimates for each MSOA-year cell. We first sample from the posterior and extract the fixed effects, spatial area effect, and temporal effect. We then rebuild the fitted model for every MSOA-year aggregation row and summarise the resulting draws.

Note

Each posterior draw stores the fixed effects, spatial area effect, and temporal effect together in INLA’s latent vector. Fixed effects are labelled as term:1, while random effects are labelled as effect:index.

# Draw 300 posterior samples from the selected fit.
set.seed(100)
posterior_draws <- inla.posterior.sample(
  n = 300,
  result = bhf_selected_fit
)

# Fixed-effect draw matrix
fixed_terms <- rownames(bhf_selected_fit$summary.fixed)
fixed_draws <- sapply(posterior_draws, \(draw) {
  setNames(
    as.numeric(draw$latent[paste0(fixed_terms, ":1"), 1]),
    fixed_terms
  )
})

# Area-effect draw matrix
area_draws <- sapply(posterior_draws, \(draw) {
  setNames(
    as.numeric(draw$latent[paste0("area_inla_id:", area_ids), 1]),
    area_ids
  )
})

# Time-effect draw matrix
time_draws <- sapply(posterior_draws, \(draw) {
  setNames(
    as.numeric(draw$latent[paste0("time_inla_id:", time_ids), 1]),
    time_ids
  )
})

Each posterior draw is evaluated over the MSOA-year aggregation frame.

prediction_matrix <- model.matrix(
  ~ age + female + car_access,
  data = aggregation_data
)[, fixed_terms, drop = FALSE]

prediction_draws <- sapply(seq_along(posterior_draws), \(draw_id) {
  log_odds <- as.numeric(prediction_matrix %*% fixed_draws[, draw_id]) +
    area_draws[as.character(aggregation_data$area_inla_id), draw_id] +
    time_draws[as.character(aggregation_data$time_inla_id), draw_id]

  plogis(log_odds) # For binomial model
})

The matrix prediction_draws has one MSOA-year estimate per row and one posterior draw per column. Posterior means, variances, and 95% credible intervals are computed directly from this draw matrix.

final_bhf_results <- aggregation_data |>
  select(area_id, time_id) |>
  bind_cols(
    tibble(
      bhf_estimate = rowMeans(prediction_draws),
      bhf_variance = apply(prediction_draws, 1, var),
      bhf_lower = apply(prediction_draws, 1, quantile, probs = 0.025, names = FALSE),
      bhf_upper = apply(prediction_draws, 1, quantile, probs = 0.975, names = FALSE)
    )
  ) |>
  mutate(
    bhf_ci_width = bhf_upper - bhf_lower
  )

Even with unit-level fitting to overcome weak direct estimation, the aggregation step using area summaries relies on strong assumptions about each area’s population composition. Representing age, sex, and car access with area-level summaries, such as mean age, proportion female, and share of households with car access, can hide important compositional differences. Two areas may have similar summaries but very different age-sex-car structures, meaning the model could produce similar estimates even where cycling behaviour differs across specific combinations of these predictors.

This limitation can be addressed by using a poststratification table that contains population counts for the joint distribution of the relevant predictors. This is the logic of Multilevel Regression with Poststratification (MRP): predict the outcome for each poststratification cell, then aggregate those predictions using the corresponding population counts so the final estimates better reflect the target population composition.
