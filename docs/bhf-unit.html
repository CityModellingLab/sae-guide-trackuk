Unit-level SAE models respondent records directly. The Battese–Harter–Fuller model first estimates the individual outcome with a nested error regression using unit-level predictors form the survey together with spatial and temporal effects, and then aggregates the predictions for each MSOA-year cell.

Theory in brief

The unit-level route models respondent outcomes directly. For the area-time target \mu_{jt}, a simple nested-error form is:

y_{ijt} = \alpha + \mathbf{x}_{ijt}^{T}\boldsymbol{\beta} + u_j + v_t + \epsilon_{ijt},

where \mathbf{x}_{ijt} are unit-level predictors, u_j is an area effect, and v_t is a time effect. The classical Battese–Harter–Fuller estimator can be applied to each area-time target:

\hat{\mu}_{jt}^{\mathrm{EBLUP}} = f_{jt} \bar{y}_{jtS} + \left(\bar{\mathbf{X}}_{jt} - f_{jt} \bar{\mathbf{x}}_{jtS}\right)^T \hat{\boldsymbol{\beta}} + (1 - f_{jt})(\hat{u}_j + \hat{v}_t),

where f_{jt}=n_{jt}/N_{jt}, \bar{y}_{jtS} and \bar{\mathbf{x}}_{jtS} are sample means in area j and time period t, \bar{\mathbf{X}}_{jt} is the corresponding population mean of the predictors, and \hat{u}_j and \hat{v}_t are fitted area and time effects. The area effect can also be replaced by a structured spatial effect.

Target estimand
  • Outcome and Population: Share of Adults who walk for transport daily
  • Geography: MSOAs in Wales
  • Time: 2021, 2023, and 2025

1 Prepare model and aggregation data

Before preparing the model inputs, we create a consistent numeric index for each area and survey year in the complete area-time domain. These indices are used by INLA to attach random effects to the correct area and period.

Code 
area_levels <- sort(unique(domain_frame[["area_id"]]))
time_levels <- sort(unique(domain_frame[["time_id"]]))

area_index <- tibble(
  area_id = area_levels,
  area_inla_id = seq_along(area_levels)
)

time_index <- tibble(
  time_id = time_levels,
  time_inla_id = seq_along(time_levels)
)

To include a spatial random effect, we also need an adjacency graph .adj as input. We again use Queen contiguity.

Code 
msoa_boundaries_sorted <- msoa_boundaries |>
  inner_join(area_index, by = "area_id") |>
  arrange(.data$area_inla_id)

msoa_neighbours <- poly2nb(
  msoa_boundaries_sorted,
  queen = TRUE,
  row.names = msoa_boundaries_sorted$area_id
)

spatial_graph_file <- tempfile(fileext = ".adj")

nb2INLA(
  file = spatial_graph_file,
  nb = msoa_neighbours
)

We now prepare the two datasets needed for the unit-level INLA workflow:

  • model_data contains the sampled respondent records used to fit the model.
  • aggregation_data contains one row for each area-time cell we want to estimate.

1.1 Respondent model data

The respondent model data has one row per sampled person. For this constrained example we use:

  • indicator as the binary response, our target;
  • no_car as the unit-level auxiliary variable, our predictor;
  • time_id as the survey wave year identifier;
  • area_id as the area identifier;

2 Fit and evaluate models

We fit linear mixed models to respondent-level records, then use them to predict area-time means. Because the response variable is binary, the fitted values are interpreted as predicted probabilities.

We specify two unit-level models to evaluate at the next step:

Model Name Specifications
M1 Temporal + spatial Respondent outcome with a temporal random walk and BYM2 spatial MSOA effect
M2 +No-car M1 plus respondent-level no-car access 
m1_formula <- indicator ~
  1 +
  f(time_inla_id, model = "rw1", constr = TRUE) +
  f(
    area_inla_id,
    model = "bym2",
    graph = spatial_graph_file,
    scale.model = TRUE,
    constr = TRUE
  )

m2_formula <- indicator ~
  no_car +
  f(time_inla_id, model = "rw1", constr = TRUE) +
  f(
    area_inla_id,
    model = "bym2",
    graph = spatial_graph_file,
    scale.model = TRUE,
    constr = TRUE
  )

model_formulas <- list(
  "M1 Temporal + Spatial" = m1_formula,
  "M2 +No-car" = m2_formula
)

Conceptually, the workflow has two steps: fit the respondent-level model, then evaluate it for each area-time. We implement this by binding the observed respondent rows and the area-time aggregation rows into a single input table before fitting. The area-time rows to have their estimates predicted have indicator = NA, signalling to INLA to return fitted values for them.

model_agg_data <- bind_rows(
  model_data |>
    transmute(
      row_type = "model",
      indicator,
      no_car,
      time_inla_id,
      area_inla_id
    ),
  aggregation_data |>
    transmute(
      row_type = "aggregation",
      indicator = NA_real_,
      no_car,
      time_inla_id,
      area_inla_id
    )
)

fit_bhf_model <- function(formula) {
  inla(
    formula = formula,
    family = "gaussian",
    data = model_agg_data,
    control.predictor = list(compute = TRUE),
    control.compute = list(waic = TRUE)
  )
}

bhf_fits <- lapply(model_formulas, fit_bhf_model)
Note

When fitting unit-level BHF models with INLA, these arguments are needed:

  • control.predictor = list(compute = TRUE) ensures that fitted values are returned for the full input table, so the predictions for the aggregation rows can be extracted after fitting.
  • control.compute = list(waic = TRUE) requests WAIC for comparing model fit across candidate specifications.

To compare the fitted models’ overall performance, we again use WAIC as a first check. WAIC is a global predictive-fit measure returned by INLA; lower values indicate better expected prediction after penalising model complexity. Here, the lower WAIC for M2 shows that adding the no-car predictor improves the model predictive power as expected.

The temporal tau is high, suggesting that the survey-wave adjustments are relatively small. By contrast, the spatial tau is lower, indicating more remaining variation between MSOAs than between survey waves. The BYM2 phi is above 0.5, so in this simple BHF model specification much of the remaining between-MSOA variation is spatially structured. By contrast, the lower phi in the Fay–Herriot model may reflect its richer specification: with more area-level predictors included, less residual between-MSOA variation is left for the spatial random effect to explain.

3 Report estimates and uncertainty

Using M2 as the selected model, we extract predictions for the target area-time rows, marked in the INLA input as row_type == "aggregation". We then report the posterior mean as the final estimate and use the lower and upper bounds of the 95% credible interval to describe uncertainty.

Code 
bhf_m2_fitted_values <- bhf_fits[["M2 +No-car"]]$summary.fitted.values |>
  as_tibble() |>
  slice(which(model_agg_data$row_type == "aggregation"))

bhf_m2_results <- bind_cols(
  aggregation_data |> select(area_id, msoa_name, time_id),
  bhf_m2_fitted_values
) |>
  transmute(
    area_id,
    msoa_name,
    time_id,
    bhf_estimate = pmin(pmax(mean, 0), 1),
    bhf_variance = sd^2,
    bhf_lower = pmin(pmax(.data[["0.025quant"]], 0), 1), # clipped to [0,1] since estimate is a share
    bhf_upper = pmin(pmax(.data[["0.975quant"]], 0), 1), # clipped to [0,1] since estimate is a share
    bhf_ci_width = bhf_upper - bhf_lower
  )

In practice, modelled estimates should be reported alongside the direct-estimate metadata. This keeps the sample size, direct estimate, and direct-estimate variance in the final output, making it easier to compare the modelled result with the survey evidence it builds on.

Code 
direct_estimates <- read_csv(

  left_join(direct_estimates, by = c("area_id", "time_id")) |>

    n,

    variance,
    bhf_estimate,
    bhf_variance,
    bhf_lower,
    bhf_upper,

However, the BHF and Fay–Herriot estimates could still differ because the two models use the survey information differently. This simple BHF example is fitted to unweighted respondent records and uses only one respondent-level predictor. The final Fay–Herriot model starts from weighted direct estimates, uses their sampling variances, and includes a richer set of area-level predictors and spatio-temporal effects.

Adding more unit-level predictors such as age, sex, ethnicity, or employment status can help; aggregation then requires a population table with the joint distribution of those predictors for every area-time cell. This requirement leads to multilevel regression with poststratification: MRP fits a richer unit-level model and averages predicted outcomes over a poststratification table representing the target population.
