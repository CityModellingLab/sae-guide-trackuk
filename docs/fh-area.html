Area-Level SAE Modeling (Fay–Herriot)”

A Bayesian spatio-temporal extension

Theory in brief

The Fay–Herriot model treats each direct estimate as a noisy observation of the true area-time quantity:

\hat{\mu}^{w}_{jt} = \mu_{jt} + e_{jt}, \qquad e_{jt} \sim \mathcal{N}(0, \psi_{jt}),

where \psi_{jt} is the sampling variance estimated from the survey design. The latent area-time mean is then modelled using predictors and an area random effect:

\mu_{jt} = \alpha + \mathbf{x}_{jt}^{T}\boldsymbol{\beta} + u_j.

Here u_j borrows strength across areas while the target remains the area-time quantity \mu_{jt}. The area effect can be replaced by a structured spatial effect, and a temporal effect v_t can be added to represent wave-to-wave dependence. The fitted model gives an area-time estimate by combining the direct estimate with the model prediction:

\hat{\mu}_{jt}^{\mathrm{FH}} = \widehat{\mathbb{E}}(\mu_{jt} \mid \hat{\mu}^{w}_{jt}, x_{jt}).

Here u_j borrows strength across areas while the target remains the area-time quantity \mu_{jt}. The area effect can be replaced by a structured spatial effect, and a temporal effect v_t can be added to represent wave-to-wave dependence.

Estimation approach

Target estimand
  • Outcome and Population: Share of Adults who walk for transport daily
  • Geography: MSOAs in Wales
  • Time: 2021, 2023, and 2025

Area-level SAE starts from the direct estimates created in the previous step. The Fay–Herriot model treats each direct estimate for an area-time cell, an MSOA-year cell in this example, as a noisy observation of the underlying frequent-walking rate, using its sampling variance to control how much confidence the model places in that value.

The model then borrows strength across MSOAs and survey years using spatial and temporal random effects, together with scaled MSOA-level predictors from ONS UK Census 2021, including age and sex summaries, population density, car-access household share, working-from-home share, student share, and occupation profile. This stabilises weak or missing direct estimates while retaining survey-design information.

The missing or zero sampling variances of direct estimates need to be handled, because it controls how much weight each direct estimate receives in the FH model.

  • For area-time cells without a direct estimate or variance, we assign the maximum observed positive sampling variance, signalling high uncertainty. Their estimates will be mostly model predictions.
  • Because the outcome is binary (1 for walking daily, 0 otherwise), very small samples can produce a variance of 0 when all sampled respondents give the same response. We also assign these cells the maximum observed positive sampling variance.
max_variance <- max(direct_walk$variance[direct_walk$variance > 0], na.rm = TRUE)

direct_walk_model <- direct_walk |>
  mutate(
    adj_variance = case_when(
      is.na(direct_estimate) ~ max_variance,
      is.na(variance) ~ max_variance,
      variance <= 1e-8 ~ max_variance,
      TRUE ~ variance
    )
  )

2 Fit and evaluate models

Each model uses the direct estimate as the response. The sampling variance from the direct estimation is passed to INLA as known observation-level uncertainty, so cells with noisy direct estimates receive less weight. We define these model specifications and fit each one to the direct estimates using INLA.

Model Name Specifications
M0 Baseline Intercept plus independent area effect
M1 +Demographic M0 plus mean age and proportion female
M2 +Core predictors M1 plus population density and car-access household share
M3 +All predictors M2 plus economic activities (full-time students, semi-routine/routine occupation, WFH)
M4 +TempSpatial M3 plus temporal random walk and BYM2 spatial MSOA effect

The choice of spatial and temporal models should reflect assumptions about how residual variation is structured across space and time.

Temporal model Description
rw1 First-order random walk: smooths neighbouring time periods.
rw2 Second-order random walk: smooths changes in the trend over longer time series.
ar1 Autoregressive effect: assumes correlation decays with time distance, so closer years are more similar than distant years.
Spatial model Description
besag Smooths estimates across neighbouring areas, capturing spatially structured residual variation.
bym2 Updated BYM model with a mixing parameter, phi, which indicates how much residual variation is spatially structured.

With only three survey years, rw1 is suitable because it smooths neighbouring waves. Spatially, bym2 is appropriate because it allows the model to borrow strength from neighbouring MSOAs while still capturing unstructured local variability.

fit_fh_model <- function(formula) {
  inla(
    formula = formula,
    family = "gaussian",
    data = model_data,
    scale = 1 / model_data$adj_variance,
    control.family = list(
      hyper = list(
        prec = list(initial = 0, fixed = TRUE)
      )
    ),
    control.predictor = list(compute = TRUE),
    control.compute = list(waic = TRUE)
  )
}

fh_fits <- lapply(model_formulas, fit_fh_model)
Note

When fitting area-level FH models with INLA, these arguments are needed:

  • control.predictor = list(compute = TRUE) returns fitted values for every row. In an area-level model, these are the final estimates for each area-time row.
  • scale passes the inverse sampling variance to INLA, so less precise direct estimates get smoothed more.
  • control.family fixes the Gaussian residual precision because the direct-estimate variances already provide the uncertainty.
  • control.compute = list(waic = TRUE) requests WAIC for comparing model fit in case of multiple specifications.

To compare the fitted models’ overall performance, we use WAIC or (Widely Applicable Information Criterion) as a first check. It is a global predictive-fit measure returned by INLA; lower values indicate better expected prediction after penalising model complexity.

3 Final estimates and uncertainty

To extract the estimates for this model, we take the fitted-value summary from the INLA object and bind it back to the area-time rows used in the model fit. For transparency, the output also retains the direct estimates, sample sizes, and direct-estimate variances. The final model estimates are reported with uncertainty, shown here using the width of the posterior 95% credible interval.

4.2 Adding Predictors

After the WAIC comparison, we inspect local estimate changes to see where the model moves the target estimates and whether those movements are substantively plausible. In Fay-Herriot SAE, adding predictors changes the expected value for each area-time cell, and unstable direct estimates are pulled more strongly toward those updated model predictions when the predictors are relevant.

For example, moving from M2 to M3 adds the occupation and work-pattern predictors. We map where M3 changes the estimates relative to M2, then summarise the predictor profiles of the areas with the largest upward and downward shifts (top and bottom 10%).

4.3 Adding Temporal And Spatial Effects

The contribution of the temporal and spatial effects on the model prediction can be examined through two diagnostic outputs by INLA:

  • tau is the precision of the random effect, or the inverse of its variance. A higher tau means the random effect varies less.
  • phi is the BYM2 mixing parameter: it indicates how much of the area random effect is assigned to the structured spatial component versus the unstructured component. A value of 0.5 means the structured and unstructured components contribute roughly equally to the area random effect.
Code 
fh_fits[["M4 +TempSpatial"]]$summary.hyperpar |>
  as_tibble(rownames = "parameter") |>
  filter(str_detect(parameter, "time_inla_id|area_inla_id|Phi")) |>
  select(parameter, mean, sd, `0.025quant`, `0.5quant`, `0.975quant`) |>
  mutate(across(where(is.numeric), ~ round(.x, 3)))
