Direct Estimation

Design-based direct estimates and their sampling variances

Direct estimation is the design-based starting point for the SAE workflow. At this stage, each MSOA-year estimate is calculated only from the survey respondents observed in that MSOA and wave, using the matched survey weight.

1 Calculate direct estimates

We estimate the share of adults who walk for transport daily in each MSOA-year using a Horvitz–Thompson weighted proportion among usable adult respondents. The cleaned survey microdata input has one row per respondent-wave for the walking estimand. After filtering, each retained row has a valid binary walking response, matched analysis weight, MSOA assignment, wave label, and survey stratum:

Column Role
msoa_code MSOA estimation area
wave_year Survey wave / year
indicator Binary response: 1 if the adult walks for transport daily, 0 otherwise
weight Matched walking weight
strata Local Authority code

We use survey::svyby() to compute the weighted share and its uncertainty diagnostics for every MSOA-year cell with usable observations. It then completes the MSOA-by-wave grid so missing cells are retained for modelling.

# Define survey design
walk_design <- survey::svydesign(
  ids = stats::as.formula("~1"),
  strata = stats::as.formula("~strata"),
  weights = stats::as.formula("~weight"),
  data = survey_walk
)

# Calculate direct estimate and uncertainty
direct_walk_estimates <- survey::svyby(
  formula = stats::as.formula("~indicator"),
  by = stats::as.formula("~msoa_code + wave_year"),
  design = walk_design,
  FUN = survey::svymean,
  vartype = "se",
  na.rm = TRUE,
  keep.names = FALSE
) |>
  tibble::as_tibble() |>
  transmute(
    msoa_code,
    wave_year,
    direct_estimate = .data$indicator,
    standard_error = .data$se
  ) |>
  mutate(variance = .data$standard_error^2)

# Calculate sample size per MSOA-year
direct_walk_counts <- survey_walk |>
  group_by(across(all_of(c("msoa_code", "wave_year")))) |>
  summarise(n = dplyr::n(), .groups = "drop")

# Join
direct_walk <- domain_frame |>
  left_join(direct_walk_estimates, by = c(
    "msoa_code", "wave_year"
  )) |>
  left_join(direct_walk_counts, by = c(
    "msoa_code", "wave_year"
  )) |>
  mutate(n = replace_na(.data$n, 0L))

2 Evaluate direct estimates

Direct estimation provides a useful starting point because they make three limitations visible:

  • Uneven temporal and spatial coverage: The number of usable observations varies across survey waves and across MSOAs. This means some MSOA-year estimates are based on much less direct evidence than others.
  • Unstable area estimate over time: For some MSOAs, direct estimates change sharply between waves. These changes may reflect real behavioural change, but they may also reflect sampling noise.
  • Zero within-area variance: For binary indicators, especially with small samples, some MSOAs show no within-area variation because all respondents give the same response. This can produce zero or unrealistically low variances.

  plot.subtitle = element_text(size = 12, hjust = 0.5, colour = "grey30")

base_map <- function(wave) {
  wave_direct <- direct_walk[direct_walk[["wave_year"]] == wave, ]

  wave_data <- msoa_boundaries |>
    left_join(wave_direct, by = "msoa_code")

  ggplot(wave_data) +
    theme_void() +
    map_text_theme
}

plot_estimate <- function(wave) {
  base_map(wave) +
    geom_sf(aes(fill = .data$direct_estimate), colour = "transparent") +
    scale_fill_viridis_c(
      option = "magma",
      limits = c(0, 1),
      labels = scales::label_percent(accuracy = 1),
      na.value = "grey85",
      name = "Share"
    )
}

plot_uncertainty <- function(wave) {
  base_map(wave) +
    geom_sf(aes(fill = .data$variance), colour = "transparent") +
    scale_fill_distiller(
      palette = "Oranges",
      direction = 1,
      na.value = "grey85",
      limits = c(0, max(direct_walk$variance, na.rm = TRUE)),
      labels = scales::label_number(accuracy = 0.001),
      name = "Variance"
    )
}

plot_sample <- function(wave) {
  base_map(wave) +
    geom_sf(aes(fill = .data$n), colour = "transparent") +
    scale_fill_gradient(
      low = "#fff8e1",
      high = "#4f3b10",
      limits = c(0, max(direct_walk$n, na.rm = TRUE)),
      na.value = "grey85",
      name = "Sample size"
    )
}

Model-based approaches are designed to address these issues. Area-level models can stabilise noisy direct estimates by borrowing strength from area-level predictors. Unit-level models go a step further by modelling individual outcomes directly, which helps avoid problems caused by zero or unreliable within-area variance estimates.
