BHF unit-level SAE starts from respondent records rather than area-level direct estimates. Here we use a Bayesian extension of the Battese–Harter–Fuller model: individual responses borrow strength from respondent-level predictors and area/time random effects, then the fitted relationship is aggregated to MSOA–year estimates using known area-level predictor means.

A reminder that our target estimand is:

Share of Welsh adults who walk for transport daily by MSOA in 2021, 2023 and 2025

1 Define Domain, Indices And Spatial Graph

Before preparing the model inputs, we create a consistent numeric index for each MSOA and survey year in the complete MSOA–year domain. These indices are used by INLA to attach random effects to the correct area and period.

area_levels <- sort(unique(domain_frame[["msoa_code"]]))
year_levels <- sort(unique(domain_frame[["wave_year"]]))

area_index <- tibble(
  msoa_code = area_levels,
  area_id = seq_along(area_levels)
)

year_index <- tibble(
  wave_year = year_levels,
  year_id = seq_along(year_levels)
)

To include a spatial random effect, we also need an adjacency graph .adj as input. We again use Queen contiguity.

msoa_boundaries_sorted <- msoa_boundaries |>
  inner_join(area_index, by = "msoa_code") |>
  arrange(.data$area_id)

msoa_neighbours <- poly2nb(
  msoa_boundaries_sorted,
  queen = TRUE,
  row.names = msoa_boundaries_sorted$msoa_code
)

spatial_graph_file <- tempfile(fileext = ".adj")

nb2INLA(
  file = spatial_graph_file,
  nb = msoa_neighbours
)

2 Prepare Model And Aggregation Data

BHF modelling has two separate data-preparation tasks:

  • prepare the respondent-level rows used to fit the model;
  • prepare the area-level rows used to aggregate the fitted relationship to MSOA–year estimates.

2.1 Respondent Model Data

The respondent model data has one row per sampled person. For this constrained example we use:

  • indicator as the binary response, our target;
  • no_car as the unit-level auxiliary variable, our predictor;
  • wave_year as the survey wave year identifier;
  • msoa_code as the area identifier;
unit_predictors <- read_csv(

3 Fit And Evaluate Models

We fit linear mixed models to respondent-level records, then use them to predict MSOA–year means. This follows the BHF nested-error idea, extended here with temporal and spatial random effects.

Note

The response is binary, so this is a linear probability version of the BHF-style model.

The two models are:

Model Name Specifications
M1 Temporal + spatial Respondent outcome with a temporal random walk and BYM2 spatial MSOA effect
M2 +No-car M1 plus respondent-level no-car access, aggregated using the MSOA Census share of households with no car or van 
m1_formula <- indicator ~
  1 +
  f(year_id, model = "rw1", constr = TRUE) +
  f(
    area_spatial_id,
    model = "bym2",
    graph = spatial_graph_file,
    scale.model = TRUE,
    constr = TRUE
  )

m2_formula <- indicator ~
  no_car +
  f(year_id, model = "rw1", constr = TRUE) +
  f(
    area_spatial_id,
    model = "bym2",
    graph = spatial_graph_file,
    scale.model = TRUE,
    constr = TRUE
  )

model_formulas <- list(
  "M1 Temporal + Spatial" = m1_formula,
  "M2 +No-car" = m2_formula
)

INLA does not use a separate predict(newdata = ...) step; instead, it returns fitted values for every row in the input data. We therefore add aggregation MSOA–year rows with indicator = NA for INLA to return fitted values for them.

Note

In the Fay–Herriot model, this feature allows for MSOA–years without survey data (unsampled) to also receive an estimate.

inla_input <- bind_rows(
  model_data |>
    transmute(
      row_type = "model",
      indicator,
      no_car,
      year_id,
      area_spatial_id
    ),
  aggregation_data |>
    transmute(
      row_type = "aggregation",
      indicator = NA_real_,
      no_car,
      year_id,
      area_spatial_id
    )
)

fit_bhf_model <- function(formula) {
  inla(
    formula = formula,
    family = "gaussian",
    data = inla_input,
    control.predictor = list(compute = TRUE),
    control.compute = list(waic = TRUE, dic = TRUE)
  )
}

bhf_fits <- lapply(model_formulas, fit_bhf_model)

WAIC compares the BHF fits to the sampled respondent outcomes. Here, the lower WAIC for M2 shows that adding the no-car predictor improves the temporal-spatial model enough to justify the extra term.

Finally, the spatial and temporal random-effect hyperparameters help show what the temporal and spatial terms are doing in the selected model. The temporal term has a precision parameter tau; the BYM2 spatial term has both tau and phi.

  filter(str_detect(.data$parameter, "year_id|area_spatial_id|Phi")) |>
  select(parameter, mean, sd, `0.025quant`, `0.5quant`, `0.975quant`) |>

Precision for year_id 6082.178 13381.854 396.208 2657.463 33865.434

The temporal tau is high, suggesting that the survey-wave adjustments are relatively small. By contrast, the spatial tau is lower, indicating more remaining variation between MSOAs than between survey waves.

Interestingly, the BYM2 phi is high and above 0.5, suggesting that much of the remaining area-level variation in the BHF model is spatially structured. This may look different from the lower phi seen in the Fay–Herriot model, but the two values are not directly comparable. They come from different modelling units and specifications: the BHF model is fitted to individual respondent records, while the Fay–Herriot model is fitted to area-level direct estimates and their sampling variances. Therefore, the higher phi here should be read as evidence that, within this simpler unit-level specification, the remaining between-MSOA differences are spatially patterned.

With M2 being the most performant, we now collate the final fitted values for the aggregation rows into one MSOA–year results table.

The Fay–Herriot model starts from weighted direct estimates and their sampling variances, so it remains closely tied to the design-based survey estimator. The BHF model is fitted directly to respondent records and does not fully account for survey weights or the complex survey design. If some groups are over-sampled, under-sampled, or unevenly distributed across areas, they can pull the fitted unit-level relationship away from the target population.

The model is also under-specified. It only includes no-car access, time, and spatial structure. Adding age, sex, ethnicity, employment status, or other respondent-level predictors would help account for sample composition, but it also raises the data requirement. For aggregation, we would no longer need only the MSOA mean of no_car; we would need a population table giving the joint distribution of all predictors used in the model.

That is the bridge to multilevel regression and poststratification. MRP fits a richer unit-level model, then averages the predicted outcomes over a poststratification table representing the target population. The next workbook takes that step.

Area-level estimation
MRP
