Small Area Estimation with Poststratification (MRP)

A Bayesian spatio-temporal extension

Theory in brief

Let c index poststratification cells within area j and time t. The cells are defined by whichever population variables are available for poststratification. In a unit-level MRP approach, a binary walking outcome can be modelled at the respondent level as

\begin{aligned} Y_{ijt} &\sim \mathrm{Bernoulli}(\pi_{ijt}) \\ \mathrm{logit}(\pi_{ijt}) &= \alpha + z_{ijt}^{T}\beta + u_j + v_t . \end{aligned}

where z_{ijt} is a vector of respondent-level predictors used to define or adjust the poststratification cells, \beta contains their coefficients, u_j is an area effect, and v_t is a time effect. The fitted model gives predicted cell means for the binary frequent-walking indicator in each poststratification cell:

\hat{\pi}_{jtc} = \widehat{\mathbb{E}}(Y \mid j,t,c).

The poststratification step combines those cell predictions with population counts N_{jtc} available or estimated for the same cells. Area-time estimates are then population-weighted averages of the cell predictions. \hat{\mu}_{jt}^{\mathrm{MRP}} = \frac{\sum_c N_{jtc}\hat{\pi}_{jtc}} {\sum_c N_{jtc}}.

Estimation approach

Target estimand
  • Outcome and Population: Share of Adults who walk for transport daily
  • Geography: MSOAs in Wales
  • Time: 2021, 2023, and 2025

MRP extends the unit-level SAE workflow by combining a respondent-level outcome model with a poststratification table describing the target population. For our estimand, we model the binary frequent-walking indicator using age_band (to reflect the age composition in the poststratification table), sex, car_access, and spatial and temporal random effects. We then produce predicted cell means for the binary frequent-walking indicator for each age_band × sex × car_access population cell and aggregate them to MSOA-year estimates using population weights. Uncertainty is propagated by repeating this aggregation across posterior draws.

One data limitation is that the available ONS poststratification table only contains age_band × sex population counts. To include car_access, we first estimate car-access probabilities for each age_band × sex cell and use them to extend the poststratification table. This avoids applying the same MSOA-level car-access share to every age-sex cell, but it introduces additional uncertainty because part of the population table is modelled rather than directly observed. A more conservative alternative would be to model walking using only age_band and sex, and use MSOA-level car-access share separately as a contextual area-level predictor.

1.3 Adding car access into poststratification table

The poststratification table has age-sex population counts, but it does not contain the joint distribution of age, sex, and car access. We first model respondent car access using the variables that are available in the poststratification table. We then predict the probability of car_access = 1 for each age-sex-area-time population cell and use those probabilities to expand the poststratification table.

fit_mrp_model <- function(formula) {
  inla(
    formula = formula,
    family = "binomial",
    Ntrials = 1,
    data = model_poststrat_data,
    control.predictor = list(compute = TRUE, link = 1),
    control.compute = list(waic = TRUE, config = TRUE)
  )
}

At this point, having selected our final model, we use poststratification to convert its cell-level predictions into the target MSOA-year estimates. That means, each age_band x sex x car_access cell prediction is weighted by its population count, then aggregated within each MSOA-year. One the one hand, we can apply this calculation using the posterior mean cell values returned above, which gives a simple point-estimate for each cell:

Code 
mrp_final_fit <- mrp_fits[["M2 +CarAccess"]]
poststrat_cell_rows <- which(model_poststrat_data$row_type == "poststrat")

cell_mean_predictions <- mrp_final_fit$summary.fitted.values |>
  as_tibble() |>
  slice(poststrat_cell_rows) |>
  transmute(cell_mean = mean)

cell_point_estimates <- bind_cols(poststrat_data, cell_mean_predictions)

area_year_point_estimates <- cell_point_estimates |>
  group_by(area_id, time_id) |>
  summarise(
    weighted_cell_sum = sum(cell_mean * pop_count),
    population_total = sum(pop_count),
    .groups = "drop"
  ) |>
  mutate(mrp_point_estimate = weighted_cell_sum / population_total) |>
  select(area_id, time_id, mrp_point_estimate)

However, the final output for SAE also needs uncertainty estimates. To propagate uncertainty through poststratification, we repeat the same population-weighted aggregation across posterior draws. This means the credible intervals describe uncertainty in the aggregated MSOA-year estimates, not just uncertainty in the individual cell predictions. The posterior draws used for this calculation are shown below.

3 Final estimates and uncertainty

The function inla.posterior.sample() gives plausible versions of the fitted model; for each draw, we keep the poststratification rows and convert their fitted values from the logit scale to the original scale of the outcome (0-1).

# Draw plausible versions of the fitted model from the posterior.
set.seed(100)
posterior_draws <- inla.posterior.sample(n = 300, result = mrp_final_fit)

# Rows are poststrat cells; columns are posterior draws; values are predicted cell means.
estimate_draws <- matrix(NA_real_, nrow = nrow(poststrat_data), ncol = length(posterior_draws))

predictor_row_index <- startsWith(rownames(posterior_draws[[1]]$latent), "Predictor")

for (draw_id in seq_along(posterior_draws)) {
  draw <- posterior_draws[[draw_id]]
  row_prediction_logits <- as.numeric(draw$latent[predictor_row_index, 1])
  poststrat_logits <- row_prediction_logits[poststrat_cell_rows]
  poststrat_cell_means <- 1 / (1 + exp(-poststrat_logits))
  estimate_draws[, draw_id] <- poststrat_cell_means
}

The matrix estimate_draws contains the draw-level predicted cell means. Using it, we poststratify each posterior draw. That means, for every draw, the predictions are weighted by the corresponding population counts, summed within each MSOA-year, and divided by the total MSOA-year population. This gives one population-weighted estimate per MSOA-year for each posterior draw.

area_year_id <- paste(poststrat_data$area_id, poststrat_data$time_id, sep = "__")

# Population-weight cell means and aggregate them to MSOA-year estimates.
area_year_weighted_sums <- rowsum(estimate_draws * poststrat_data$pop_count, group = area_year_id, reorder = FALSE)
area_year_populations <- rowsum(poststrat_data$pop_count, group = area_year_id, reorder = FALSE)

area_year_means <- area_year_weighted_sums / as.numeric(area_year_populations)

A closer look at the difference between the unit-level BHF and MRP estimates reveals subtle differences in how population composition is handled. The BHF workflow aggregates using area-level summaries, so it cannot fully represent the internal age, sex, and car-access composition of each MSOA-year. MRP instead predicts over the age_band x sex x car_access poststratification cells and then weights those cells by their population counts.

MRP estimates should therefore be higher than BHF estimates where the poststratification table gives more weight to groups with higher predicted frequent-walking rates. Where those groups make up a larger share of a local population than the BHF area-level summaries can represent, MRP will tend to shift the estimate upward.
