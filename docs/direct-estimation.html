Direct estimation is the starting point for the SAE workflow. At this stage, each area-time estimate, or an MSOA-year cell in this example, is calculated only from the survey respondents observed in that area and wave, using the matched survey weight. This gives us a transparent baseline before any model-based smoothing is introduced and shows where direct estimates are unstable, missing, or based on very small samples, helping us decide whether model-based small area estimation is needed.

Theory in brief

For an area-time cell \((j,t)\), the target is the population mean or proportion:

\[ \mu_{jt} = \frac{1}{N_{jt}}\sum_{i=1}^{N_{jt}} y_{ijt}. \]

If respondent \(i\) has inclusion probability \(\pi_{ijt}\) and survey weight \(w_{ijt}=1/\pi_{ijt}\), the Horvitz–Thompson ratio estimator is:

\[ \hat{\mu}^{w}_{jt} = \frac{\sum_{i \in S_{jt}} w_{ijt} y_{ijt}} {\sum_{i \in S_{jt}} w_{ijt}}. \]

Target estimand
  • Outcome and Population: Share of Adults who walk for transport daily
  • Geography: MSOAs in Wales
  • Time: 2021, 2023, and 2025

1 Prepare survey data

We use a Horvitz–Thompson weighted proportion among usable adult respondents. The cleaned survey microdata input has one row per respondent-wave for the walking estimand. After filtering, each retained row has a valid binary walking response, matched weight, MSOA assignment, wave label, and survey stratum:

Column Role
area_id Estimation area
time_id Survey wave / year
indicator Binary response: 1 if the adult walks for transport daily, 0 otherwise
weight Matched weight

2 Calculate direct estimates

We use svyby() from the survey package to compute the weighted share and its uncertainty diagnostics for every area-time cell with usable observations. It then completes the area-by-time grid so missing cells are retained for modelling.

# Define survey design
walk_design <- svydesign(
  ids = as.formula("~1"),
  strata = as.formula("~strata"),
  weights = as.formula("~weight"),
  data = survey_walk
)

# Calculate direct estimate and uncertainty
direct_walk_estimates <- svyby(
  formula = as.formula("~indicator"),
  by = as.formula("~area_id + time_id"),
  design = walk_design,
  FUN = svymean,
  vartype = "se",
  na.rm = TRUE,
  keep.names = FALSE
) |>
  as_tibble() |>
  transmute(
    area_id,
    time_id,
    direct_estimate = .data$indicator,
    standard_error = .data$se
  ) |>
  mutate(variance = .data$standard_error^2)

# Calculate sample size per area-time cell
direct_walk_counts <- survey_walk |>
  group_by(across(all_of(c("area_id", "time_id")))) |>
  summarise(n = n(), .groups = "drop")

# Join
direct_walk <- domain_frame |>
  left_join(direct_walk_estimates, by = c(
    "area_id", "time_id"
  )) |>
  left_join(direct_walk_counts, by = c(
    "area_id", "time_id"
  )) |>
  mutate(n = replace_na(.data$n, 0L))

3 Assess precision and coverage

Direct estimation provides a useful starting point because it makes three limitations visible:

  • Uneven temporal and spatial coverage: The number of usable observations varies across survey waves and MSOAs, leaving some area-time cells with much less direct evidence than others.
  • Unstable area estimates over time: For some MSOAs, direct estimates change sharply between waves, which may reflect real behavioural change or sampling noise.
  • Zero within-area variance: For binary indicators, small samples can contain only one response value, producing zero or unrealistically low variances.
Code 
direct_summary_by_wave <- direct_walk |>
  group_by(.data$time_id) |>
  summarise(
    `Usable observations` = sum(.data$n),
    `MSOAs without direct estimates` = sum(is.na(.data$direct_estimate)),
    `MSOAs with zero variance` = sum(.data$variance == 0, na.rm = TRUE),
    `Median sample size` = median(.data$n),
    `Median direct estimate` = round(
      median(.data$direct_estimate, na.rm = TRUE),
      3
    ),
    `Median variance` = round(
      median(.data$variance, na.rm = TRUE),
      5
    ),
    .groups = "drop"
  ) |>
  rename(`Wave` = all_of("time_id"))

Model-based approaches are designed to address these issues. Area-level models can stabilise noisy direct estimates by borrowing strength from area-level predictors. Unit-level models go a step further by modelling individual outcomes directly, which helps avoid problems caused by zero or unreliable within-area variance estimates.
